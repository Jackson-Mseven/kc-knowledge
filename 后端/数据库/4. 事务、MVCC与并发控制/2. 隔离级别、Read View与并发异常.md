# 隔离级别、Read View 与并发异常

## 并发异常

脏读读取未提交数据；不可重复读在同一事务读到不同已提交值；幻读使范围结果变化；丢失更新互相覆盖；写偏斜让局部判断都成立但整体违反规则。数据库实现和读写类型决定实际表现。

## 隔离级别

READ UNCOMMITTED 几乎不隔离；READ COMMITTED 避免脏读；REPEATABLE READ 提供一致快照；SERIALIZABLE 约束更强但冲突和重试成本高。不要只提高隔离级别而忽略唯一约束和条件更新。

## Read View 与长事务

MVCC 使用事务版本和可见性规则选择行版本。长事务持有旧快照会阻碍清理，导致 Undo/死元组膨胀、锁等待和副本延迟；事务应短且只包含数据库操作。

## 面试自测

1. 幻读能否只靠背隔离级别解决？

不能。快照读与锁定读、数据库实现和业务不变量不同；关键范围业务要用正确约束、锁和并发测试验证。
