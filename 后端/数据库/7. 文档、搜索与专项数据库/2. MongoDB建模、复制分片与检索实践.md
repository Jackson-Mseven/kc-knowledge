# MongoDB 建模、复制分片与检索实践

## 文档建模

按聚合边界决定嵌入和引用：有限、一起读写的子结构可嵌入；无限增长、共享、独立查询的实体用引用。文档并非无需 Schema，使用验证、索引、迁移和版本字段维护质量。

## 索引与查询

MongoDB 的复合索引同样受查询前缀、排序和覆盖影响。数组、多键索引、聚合管道和深分页都要读取 `explain`；限制返回字段，防止热点文档和无限数组。

## 可靠性与分片

Replica Set 提供副本和选主，Sharding 按 shard key 分布数据。分片键要匹配主要查询、避免单调写热点和频繁变更；跨分片事务、广播查询和再平衡有成本。

## 面试自测

1. MongoDB 支持事务后是否等同于关系库？

不等同。跨大量文档的频繁事务通常会带来成本并提示聚合边界不合理，关系查询和约束需求仍应影响选型。
