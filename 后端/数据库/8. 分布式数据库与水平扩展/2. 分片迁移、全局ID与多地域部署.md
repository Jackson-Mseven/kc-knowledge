# 分片迁移、全局 ID 与多地域部署

## 路由与全局 ID

路由层根据分片键定位数据。全局 ID 可使用数据库段、雪花类算法或 UUID/ULID，但需评估排序、时钟、索引和暴露风险。跨分片唯一性常需中心化服务或改为租户/分片内唯一。

## 扩缩容与迁移

再平衡应支持双写或变更捕获、数据校验、灰度读切换和回滚。分片迁移期间的权威位置、写入路由和幂等处理必须明确，不能直接复制后切 DNS。

## 多地域

地域距离增加写延迟和冲突复杂度。单写主地域更简单；多主写入需要冲突解决、时钟/版本与业务约束。数据主权、灾备和成本都影响部署决策。

## 面试自测

1. 为什么跨分片分页困难？

全局排序需要从多个分片取候选并合并，Offset 成本随页深和分片数增加；通常按分片键限定范围或设计聚合服务。
