# PostgreSQL 索引、SQL 能力、复制与 PITR

## 查询与索引

PostgreSQL 支持窗口函数、递归 CTE、`RETURNING`、物化视图和全文检索。B-tree 是通用默认；GIN 常用于 JSONB/全文，GiST 适合范围/空间，BRIN 适合与物理顺序相关的大表。用 `EXPLAIN (ANALYZE, BUFFERS)` 对实际查询验证。

## JSONB 与扩展

`jsonb` 适合扩展属性和原始事件，常用 `GIN` 索引支持包含查询；频繁过滤、排序、关联和约束的字段应提升为普通列。PostGIS、TimescaleDB、pgvector 等扩展需纳入版本、备份和托管兼容性评估。

## 复制与恢复

流复制提供物理副本，逻辑复制适合选择性同步和 CDC。基础备份配合 WAL 归档实现 PITR；故障切换前要明确同步级别、旧主隔离和连接重建。长事务会阻塞 Vacuum，导致膨胀和维护风险。

## 面试自测

1. BRIN 何时有优势？

当数据物理顺序与查询列高度相关，例如追加写的时间列，BRIN 以很小索引总结页范围，适合大表范围过滤。
