# 结构体、方法与接口

Go 使用 `struct` 描述数据，使用组合和嵌入复用行为，而不是类继承。字段首字母大写表示可被其他包访问。

接口只声明行为，类型只要实现全部方法就自动满足接口。接口应由使用方定义，保持小而专一，例如 `io.Reader`。

```go
type Reader interface { Read([]byte) (int, error) }

type User struct { Name string }
func (u User) DisplayName() string { return u.Name }
```

接口值包含动态类型和值；接口不等于 `nil` 的常见陷阱是“动态类型非空但动态值为 nil”。类型断言失败应使用带 `ok` 的形式，避免 panic。

## 组合与封装

嵌入字段会提升方法和字段访问，但不会复制状态，也不会形成传统继承关系。公开结构体要谨慎暴露可变字段；构造函数可以集中校验不变量。

## 接口边界

接口应靠近消费者定义，保持小而专一。测试替身只需实现被测代码使用的方法；接口一旦公开，新增方法会破坏所有外部实现。

## 方法集

值类型的方法集包含值接收者方法，指针类型的方法集包含值和指针接收者方法。把 `*T` 传给接口与把 `T` 传给接口可能产生不同的实现结果，编译器会在赋值处明确报错。
