# 语法基础、类型与控制流

Go 的变量有明确类型和零值：数值为 `0`，布尔为 `false`，字符串为空，指针、slice、map、channel、函数和接口可为 `nil`。短变量声明 `:=` 只能在函数体内使用。

核心集合类型是数组、slice 和 map。slice 是指向底层数组的描述符，包含指针、长度和容量；扩容可能更换底层数组，因此不要依赖底层地址稳定。

```go
items := []string{"a", "b"}
items = append(items, "c")
counts := map[string]int{"ok": 1}
for key, value := range counts {
    println(key, value)
}
```

控制流只有 `for` 一种循环形式，`switch` 默认不自动贯穿。类型转换必须显式进行，不能把整数直接当作布尔值使用。

## 常见边界

读取 `nil` map 是安全的，但写入会 panic；对 `nil` slice 进行 `append` 安全。`range` 迭代变量是每轮赋值的副本，修改它不会修改原集合元素。

## 字符串与字节

字符串是不可变的 UTF-8 字节序列，但 Go 不保证每个字符串都合法 UTF-8。按字节遍历适合协议和 ASCII，按 rune 遍历适合 Unicode 文本；按 rune 索引会产生线性扫描成本。

```go
for _, r := range "你好" {
    println(string(r))
}
```

定义新类型可以隔离单位和语义，例如 `type UserID int64`，避免把不同 ID 混用。类型别名 `type ID = int64` 不创建新类型，只改变书写名称。

## 初始化顺序

包级变量按依赖顺序初始化，随后执行 `init`，最后进入 `main`。`init` 不应承担网络连接、迁移或不可控副作用；显式构造函数更容易测试和处理错误。
