# 函数、指针与资源管理

Go 函数可以返回多个值，通常用第二个返回值表示错误。函数是一等值，可赋给变量、作为参数传递，也可以通过闭包捕获外部变量。

指针保存变量地址，但 Go 不支持指针运算。值接收者适合小型不可变值；指针接收者用于修改对象或避免复制，并决定类型是否满足接口。

`defer` 在当前函数返回前按后进先出执行，适合关闭文件、连接和解锁。它捕获参数的时机与闭包不同，循环中大量 `defer` 可能延迟资源释放。

`panic` 表示程序无法继续的异常状态，`recover` 只能在 deferred 函数中捕获；业务错误应优先返回 `error`，不要用 panic 代替流程控制。

## 闭包与循环变量

闭包捕获的是变量，而不是当时的值。循环中启动 goroutine 或保存回调时，应在循环体内创建副本或通过参数传值，避免所有闭包观察到同一个最终值。跨 Go 版本代码应把变量传参写得明确。

## 资源生命周期

打开文件、HTTP body、数据库 rows 或锁之后，立即安排对应的 `Close` 或 `Unlock`。长循环中不要把 `defer` 放在外层长函数里，应提取单次处理函数或显式关闭。
