# Go语言概览与开发环境

Go 是由 Google 开发的编译型、静态类型、垃圾回收语言，强调明确的语法、快速编译和内置并发。它常用于网络服务、云原生基础设施、命令行工具和高并发后台程序。

## 工具链

安装 Go 后，`go version` 查看版本，`go env` 查看工具链配置。常用命令包括 `go run`、`go build`、`go test`、`go fmt` 和 `go mod`。

```bash
mkdir hello && cd hello
go mod init example.com/hello
go run .
```

Go 程序从 `main` 包的 `main` 函数开始执行。模块路径应稳定且与代码托管位置一致，依赖由 `go.mod` 和 `go.sum` 管理。

## 取舍

Go 不提供类继承和隐式异常，而是使用组合、接口和显式 `error`。这降低了语言复杂度，但要求开发者主动设计错误边界和并发生命周期。

## 程序结构

Go 源文件通常由 package 声明、import、类型/变量/常量声明和函数组成。编译器会检查未使用的局部变量和 import，把许多问题提前到编译阶段。

模块路径、目录路径和包名不是完全相同的概念：一个模块可以包含多个包，一个目录通常对应一个包，`main` 包才会生成可执行程序。`internal` 和 `cmd` 是常见的工程组织约定，不是语言关键字。

## 版本意识

Go 版本会影响语言特性、标准库 API、编译器优化和安全修复。升级前应运行完整测试、race 检测和基准，尤其关注泛型、工具链和模块解析行为。
