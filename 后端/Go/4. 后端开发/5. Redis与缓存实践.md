# Redis与缓存实践

Go 服务接入 Redis 时要明确缓存键、TTL、序列化和失败策略。缓存未命中、击穿、雪崩和穿透分别需要回源保护、随机过期、限流或空值缓存等措施。

缓存不是数据唯一来源时，更新顺序和一致性窗口必须写入业务设计。客户端应复用连接池，使用 context 设置超时，并对重试次数和幂等性设上限。
