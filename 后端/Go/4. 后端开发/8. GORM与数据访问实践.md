# GORM与数据访问实践

GORM 是 Go 的 ORM，提供模型映射、CRUD、关联、事务和迁移能力。它提高常规业务开发效率，但不能替代 SQL、索引和事务边界的理解。

## 模型与查询

模型字段应明确主键、索引、零值和可空语义。读取列表时指定字段和分页，避免无意加载大字段或关联数据；对用户输入只使用参数化条件。

```go
type User struct {
    ID    uint   `gorm:"primaryKey"`
    Email string `gorm:"uniqueIndex;size:255"`
}

var user User
err := db.Where("email = ?", email).First(&user).Error
```

## 事务

事务闭包中的任意错误都必须返回，使 GORM 回滚；跨数据库或消息队列的操作不能假设一个本地事务能覆盖全部副作用。需要可靠事件时，应考虑 outbox、幂等消费和补偿机制。

## 性能与迁移

开启 SQL 日志只用于开发或受控采样环境，生产日志要脱敏。使用 `Preload` 前先确认查询数量，防止 N+1；迁移要评估锁表、回滚和大表变更窗口。连接池参数应结合 [[后端/数据库/11. 可观测性与性能工程/3. 压测、性能基线与过载保护|数据库性能工程]] 调整。
