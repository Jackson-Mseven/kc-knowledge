# gRPC与RPC

gRPC 是基于 HTTP/2 和 Protocol Buffers 的 RPC 框架，适合服务间强类型调用、流式传输和明确的接口契约。Go 实现通常使用官方 `grpc-go` 及 `protoc` 生成代码。

与 Gin 的 HTTP/JSON API 相比，gRPC 更强调内部服务的 schema、代码生成和连接复用；浏览器直接调用、开放平台兼容性和人工调试通常更适合 REST/JSON。两者可以在同一系统中分别服务内部和外部调用。

本笔记后续补充 proto 设计、拦截器、超时、状态码、流控、TLS 和兼容性策略。
