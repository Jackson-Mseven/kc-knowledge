# 标准库与网络编程

`io` 抽象流式读写，`os` 处理文件和进程，`encoding/json` 处理常见 JSON 数据，`net` 和 `net/http` 提供网络基础能力。接口组合使文件、内存缓冲区和网络连接可以复用同一套逻辑。

网络代码必须设置连接、读取和整体请求超时，并在完成后关闭 response body。客户端应复用 `http.Client` 和 Transport，避免每次请求创建新客户端造成连接浪费。
