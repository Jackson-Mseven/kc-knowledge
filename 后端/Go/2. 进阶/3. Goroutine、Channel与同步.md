# Goroutine、Channel与同步

goroutine 是由 Go 运行时调度的轻量执行单元。channel 用于在 goroutine 之间传递值并建立同步关系；关闭 channel 表示不会再发送值，不代表立即销毁接收方。

`select` 同时等待多个通信操作。`sync.Mutex` 保护共享状态，`sync.WaitGroup` 等待一组任务完成，`sync.Once` 保证初始化只执行一次。

并发代码必须明确所有权、关闭责任和退出条件。未被接收的发送、未关闭的任务循环以及无界 goroutine 都可能造成泄漏；竞态和死锁应通过测试与运行时工具定位。
