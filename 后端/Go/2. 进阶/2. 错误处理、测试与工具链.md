# 错误处理、测试与工具链

错误是值，使用 `fmt.Errorf("...: %w", err)` 保留上下文，再用 `errors.Is` 判断类别、`errors.As` 提取类型。错误信息应说明操作和对象，不应泄露凭据。

表格驱动测试适合覆盖多组输入；`go test -race ./...` 检测数据竞争，`go test -run` 可筛选用例，`go test -bench` 运行基准测试。`go fmt`、`go vet` 和静态检查应接入 CI。

模糊测试适合验证解析器、协议边界和异常输入。测试应隔离外部依赖，避免依赖执行顺序或共享可变全局状态。
