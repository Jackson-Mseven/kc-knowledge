# 包、模块与依赖管理

包是 Go 的编译单元，目录内同一包的文件共享声明。导出规则由标识符首字母决定，`internal` 目录限制可导入范围。

模块由 `go.mod` 描述路径、Go 版本和依赖。`go mod tidy` 根据源码补齐并清理依赖，`go.sum` 保存校验和。生产构建应提交这两个文件并审查依赖来源。

推荐按职责组织包，避免巨大的 `utils` 包和循环依赖。命令入口通常放在 `cmd/`，可复用业务代码放在明确命名的包中。
