# 泛型、反射与unsafe

泛型用类型参数和约束复用同一算法，适合容器、通用转换和约束明确的库代码。若泛型只隐藏简单业务分支，接口或普通函数通常更易读。

`reflect` 在运行时检查类型，适合序列化、框架适配等边界代码，但会牺牲静态检查和性能。`unsafe` 绕过类型安全与生命周期约束，升级 Go 或改变内存布局后可能失效，应限制在经过基准和测试覆盖的底层包内。
