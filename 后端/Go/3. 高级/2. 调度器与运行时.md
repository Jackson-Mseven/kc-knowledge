# 调度器与运行时

Go 运行时采用 G-M-P 模型：G 是 goroutine，M 是操作系统线程，P 提供执行 Go 代码所需的处理器资源。调度器会在阻塞、系统调用和抢占点切换任务。

`GOMAXPROCS` 控制同时执行 Go 代码的处理器数量；它不是 goroutine 总数，也不应脱离 CPU、I/O 和负载特征盲目调整。运行时行为应通过 trace 和基准测试验证。
