# 性能分析与优化

先定义延迟、吞吐、错误率和资源上限，再用基准测试、CPU/内存/阻塞 profile 和 execution trace 定位瓶颈。不要仅凭代码风格推断性能。

常见优化包括减少不必要分配、复用缓冲区、批量 I/O、控制并发和复用 HTTP 连接。优化后必须比较基线，并观察尾延迟、GC、CPU 和内存的副作用。
