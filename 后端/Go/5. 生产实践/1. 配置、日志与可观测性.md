# 配置、日志与可观测性

配置应区分必需项、默认值和敏感项，启动时校验并在日志中标识版本。结构化日志至少包含时间、级别、请求 ID 和错误上下文，禁止输出密码、Token 和个人敏感数据。

指标用于聚合趋势，日志用于事件细节，trace 用于跨服务因果链。三者应通过请求 ID 或 trace ID 关联，并为高延迟、错误率和资源耗尽设置告警。
