# 构建、部署与容器化

`go build` 生成目标平台二进制，`GOOS` 和 `GOARCH` 支持交叉编译。生产构建应固定依赖、记录版本信息，并在 CI 中执行测试和静态检查。

容器镜像应使用最小运行时、非 root 用户和只读文件系统；配置通过环境或挂载注入，不把凭据写入镜像。部署还需包含健康检查、滚动升级和回滚路径。
