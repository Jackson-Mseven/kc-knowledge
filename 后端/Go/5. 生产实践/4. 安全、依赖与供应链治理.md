# 安全、依赖与供应链治理

使用 `go mod` 管理依赖并审查模块来源、许可证和更新记录。构建环境应锁定工具链，校验模块和制品，限制 CI 凭据权限。

HTTP 服务要校验输入、限制请求体和上传大小、设置超时，并正确处理 TLS、认证和授权。安全修复应跟随官方 release notes 和依赖公告，不能只依赖一次性扫描。
