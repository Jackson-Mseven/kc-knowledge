# Extension Service Worker 与生命周期

MV3 后台 Worker 是事件驱动的，会在需要时启动、空闲时终止。它没有 `window`、DOM 和 localStorage，不能把关键状态只放在全局变量。

## 注册事件

监听器必须在模块顶层同步注册：

```js
chrome.runtime.onInstalled.addListener(({ reason }) => {
  if (reason === 'install') chrome.storage.local.set({ enabled: true })
})

chrome.action.onClicked.addListener(async (tab) => {
  if (!tab.id) return
  await chrome.scripting.executeScript({ target: { tabId: tab.id }, files: ['content.js'] })
})
```

不要先 await 初始化再注册 listener，否则事件到达时监听器可能不存在。事件内部按需加载配置。

## 状态保存

- `chrome.storage.local`：持久配置和状态；
- `chrome.storage.session`：浏览器会话内存储，适合临时数据；
- IndexedDB：大量结构化数据；
- alarms：定时唤醒，不能依赖 setInterval 永久运行；
- 全局变量只作为当前 Worker 实例缓存。

## 消息处理

```js
chrome.runtime.onMessage.addListener((message, sender, sendResponse) => {
  if (message.type !== 'GET_SETTINGS') return
  chrome.storage.local.get('settings').then(sendResponse)
  return true // 保持响应通道，具体 Promise 支持按浏览器版本核对
})
```

长连接 Port 也不应被视为永远保活；页面、标签页和 Worker 随时可能终止。协议需支持重连和重新同步。

## 安装与更新

- `runtime.onInstalled` 区分 install/update/browser update；
- 存储结构升级必须幂等并记录 schemaVersion；
- 更新期间旧页面仍可能运行旧 Content Script，消息协议保持兼容窗口；
- 不在 onInstalled 中执行无限网络迁移；失败可在后续事件重试；
- 卸载无法可靠运行清理代码，服务端数据删除需提供显式入口。

## Offscreen Document

Worker 需要 Canvas、音频、剪贴板或 DOM 解析等受支持理由时创建 Offscreen Document。创建前检查是否已存在，完成后关闭；业务 UI 不应隐藏在 Offscreen 中。

## 调试

扩展管理页打开 Service Worker 检查器，查看启动/终止、错误和事件。测试必须覆盖 Worker 被终止后重新启动，而不是只在开发期间保持 DevTools 打开。
