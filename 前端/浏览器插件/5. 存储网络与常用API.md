# 存储、网络与常用扩展 API

## Storage

| 区域 | 用途 |
| --- | --- |
| `storage.local` | 本机持久数据，容量受浏览器策略限制 |
| `storage.sync` | 跨设备小型设置，有严格配额与频率限制 |
| `storage.session` | 当前浏览器会话临时状态 |
| `storage.managed` | 企业策略下发的只读配置 |

```js
await chrome.storage.local.set({ settings: { theme: 'dark' } })
chrome.storage.onChanged.addListener((changes, area) => { /* 同步各上下文 */ })
```

写入合并语义通常以顶层 key 为单位，更新嵌套对象时先读再写并考虑并发。大量数据使用 IndexedDB，缓存设容量和淘汰。

## Tabs 与 Windows

`tabs.query/get/update/create/sendMessage` 操作标签页。读取 URL/title 等敏感字段可能需要 tabs 或 Host 权限；只操作用户当前触发页面优先 activeTab。

## Scripting

用于动态注册/执行 Content Script 和 CSS。持久动态注册需管理 ID、更新和卸载。脚本注入失败要区分权限不足、受保护页面和标签页已关闭。

## declarativeNetRequest

MV3 使用声明式规则拦截、重定向、阻止或修改部分请求头：

```json
{ "id": 1, "priority": 1, "action": { "type": "block" }, "condition": { "urlFilter": "tracker.example", "resourceTypes": ["script"] } }
```

静态、动态和会话规则有数量/优先级限制。规则不能替代完整代理逻辑；修改 CSP、Cookie 和认证头存在安全与平台限制。

## Context Menus、Commands、Notifications

- contextMenus 为选中文本、链接、图片提供动作；
- commands 注册快捷键，冲突时可能不生效，应提供设置指引；
- notifications 需克制并由明确用户价值触发；
- alarms 适合近似定时后台任务，不保证精确时间。

## Cookie 与 Identity

Cookie API 权限很高，需 Host + cookies 权限并处理 partition/store。Identity API 可完成 OAuth 跳转，仍需 PKCE、state、Token 过期和撤销；前端扩展不能安全保存 Client Secret。

## 下载与文件

downloads API 可创建和管理下载，但文件名、路径和危险文件受浏览器策略限制。不要根据网页消息任意下载可执行文件。
