# Popup、Options、Side Panel 与 DevTools

## Popup

Popup 打开时创建，失焦即关闭。适合快速动作和摘要，不适合长任务与关键未保存输入。长任务交给 Service Worker，进度写 storage，Popup 重开后恢复。

```html
<button id="inspect">检查页面</button>
<script type="module" src="popup.js"></script>
```

Popup 通过 `tabs.query({ active: true, currentWindow: true })` 获取当前页，再向 Content Script 发消息。

## Options Page

适合设置、账号、快捷键说明和数据管理。保存时校验、显示成功/错误，使用 storage.onChanged 同步到其他上下文。可选择独立页面或嵌入管理页的 options_ui。

## Side Panel

适合 AI 助手、阅读器、标签管理等持续交互。明确在哪些页面可用，处理 tab 切换和页面导航；不要假设 Side Panel 和 Content Script 始终一一对应。

## Extension Page

扩展自身页面拥有 `chrome-extension://` Origin，可使用扩展 API。路由应用要配置资源相对路径和 CSP；外部页面不能直接访问，除非声明 web_accessible_resources。

## DevTools Extension

DevTools Page 可创建 Panel，使用 inspectedWindow、network、panels 等 API。DevTools 页面、Panel、后台和 Content Script 是不同上下文，通常通过后台中转消息。

## UI 设计

- 适应浅色/深色、缩放、键盘和屏幕阅读器；
- Popup 固定合理最小/最大尺寸，文本不可溢出；
- 权限、登录和错误状态提供明确恢复操作；
- 不模仿系统安全提示或诱导点击；
- 国际化使用 `_locales` 和 i18n API，商店文案同步本地化。
