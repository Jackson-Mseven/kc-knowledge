# HTML

## 常见知识点

### 文档结构与语义化

- `<!doctype html>` 触发标准模式；缺失或写错可能进入怪异模式，导致盒模型等渲染行为不同。
- 常用语义元素：`header`、`nav`、`main`、`article`、`section`、`aside`、`footer`、`figure`、`time`。语义化能改善可读性、无障碍和搜索引擎理解。
- `section` 应有合适的标题；一段可独立分发或复用的内容更适合 `article`；仅用于布局时通常用 `div`。
- 页面通常只保留一个主要内容区域 `main`，并应有层级合理的标题结构。

### 标签与属性

- 块级与行内是默认展示特征，不是标签的绝对分类；可通过 CSS `display` 改变。
- `img` 必须提供有意义的 `alt`；纯装饰图片使用空 `alt=""`，不要省略。图片的尺寸可减少布局偏移。
- 链接使用 `a[href]`；新窗口打开的外链配合 `rel="noopener noreferrer"`，避免新页面通过 `window.opener` 操控原页面。
- `data-*` 用于存放自定义数据，通过 `element.dataset` 读取；不要把业务数据混入无关属性。
- 布尔属性的存在即表示真，例如 `disabled`；`disabled="false"` 仍然是禁用状态。

### 表单

- `label` 用 `for` 关联输入框 `id`，点击标签也能聚焦控件，并提升无障碍体验。
- `name` 是表单提交的字段名，`id` 是文档内唯一标识，二者用途不同。
- `button` 在表单中的默认类型是 `submit`；普通操作应显式写 `type="button"`。
- 原生校验属性包括 `required`、`min`、`max`、`minlength`、`maxlength`、`pattern`、`type`。前端校验只改善体验，服务端必须再次校验。
- `disabled` 的控件不会提交，也不能获得焦点；`readonly` 的值会提交，通常仍可获得焦点。

### 无障碍与 SEO

- 优先使用原生元素，例如用 `button` 处理点击行为而非给 `div` 加 `click`。原生控件自带键盘操作和语义。
- 图片替代文本、表单标签、可见焦点、正确标题层级和文档语言 `lang` 是基础无障碍要求。
- ARIA 用来补足原生语义，不应替代正确的 HTML。错误的 `role` 或 ARIA 属性会降低可访问性。
- `meta charset="UTF-8"` 指定编码；`meta name="viewport" content="width=device-width, initial-scale=1"` 是移动端视口适配基础。

### 资源加载

- 普通 `script` 会阻塞 HTML 解析；`defer` 脚本并行下载、在 DOM 解析完成后按书写顺序执行；`async` 下载完成立即执行，不保证顺序。
- `link rel="preload"` 提前获取当前页关键资源；`preconnect` 提前建立跨域连接；应只对确实关键的资源使用，避免争抢带宽。
- `iframe` 用于嵌入独立文档，可用 `sandbox` 限制其能力；跨源页面不能被当前页面随意读取，受同源策略约束。

## 面试常考题

### 1. `defer` 和 `async` 有什么区别？

`defer` 脚本在 HTML 解析完成后、`DOMContentLoaded` 前按声明顺序执行，适合存在依赖关系的脚本。`async` 脚本下载完便执行，会中断解析，执行顺序不确定，适合彼此独立的统计或第三方脚本。

### 2. 为什么要使用语义化标签？

它让代码结构更清晰，帮助搜索引擎理解内容，也让读屏软件获得正确的页面区域和内容含义。语义标签本身不等于视觉样式，仍需 CSS 控制展示。

### 3. `src` 和 `href` 的区别？

`src` 指向要嵌入或替换当前元素内容的资源，如脚本、图片；浏览器通常需要获取它才能继续处理相关内容。`href` 描述当前文档与外部资源的关联或跳转目标，如样式表和链接。

### 4. `canvas` 和 SVG 如何选择？

SVG 是基于 XML 的矢量图，图形有 DOM 节点，适合图标、简单图表和需要交互或无损缩放的场景。`canvas` 是位图绘制区域，适合高频重绘、像素处理和大量图形，例如游戏；其内部图形默认没有 DOM 语义。

### 5. 浏览器如何处理一份 HTML 文档？

浏览器解析 HTML 生成 DOM，解析 CSS 生成 CSSOM，二者结合形成渲染树，然后进行布局、绘制与合成。CSS 通常会阻塞渲染；同步脚本可能阻塞 HTML 解析，并且执行前要确保其依赖的 CSS 已就绪。

### 6. `cookie`、`localStorage`、`sessionStorage` 的区别？

`cookie` 可随同源 HTTP 请求自动发送，容量较小，常用于会话标识，需通过 `HttpOnly`、`Secure`、`SameSite` 控制安全性。`localStorage` 持久保存，`sessionStorage` 在当前标签页会话结束后清除；两者只在浏览器端可读写，不会自动随请求发送，且 API 是同步的。
