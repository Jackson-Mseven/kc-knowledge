# CSS

## 常见知识点

### 选择器、层叠与继承

- 优先级按内联样式、ID、类/属性/伪类、元素/伪元素比较；同级时后声明的规则生效。`!important` 应避免滥用。
- CSS 先比较来源与重要性，再比较优先级和书写顺序；动画、过渡和 `!important` 会影响最终层叠结果。
- `color`、`font-family` 等属性可继承；`margin`、`border`、`width` 等通常不继承。`inherit`、`initial`、`unset`、`revert` 可显式控制取值。
- 伪类描述状态，如 `:hover`、`:focus-visible`、`:nth-child()`；伪元素创建可样式化部分，如 `::before`、`::after`。

### 盒模型与尺寸

- 标准盒模型中 `width`/`height` 只指内容区；`box-sizing: border-box` 让它们包含内边距和边框，项目中常全局使用。
- 外边距会发生折叠，常见于相邻块级元素、父子第一个/最后一个块级元素；Flex、Grid、绝对定位和创建 BFC 的元素通常不会发生折叠。
- `display: none` 不参与布局且不可访问；`visibility: hidden` 保留布局空间但不可见；`opacity: 0` 保留空间且默认仍可交互。
- `overflow: hidden/auto/scroll` 可裁剪或产生滚动容器；注意滚动容器会影响 `position: sticky` 的参照与行为。

### 布局

- 普通文档流是默认布局；`float` 原用于文字环绕，现代页面布局优先用 Flexbox 或 Grid。
- Flexbox 适合一维布局。主轴由 `flex-direction` 决定，`justify-content` 控制主轴分配，`align-items` 控制交叉轴对齐；`flex: 1` 常等价于 `1 1 0%`。
- Grid 适合二维布局，`fr` 分配剩余空间，`repeat()`、`minmax()` 与 `auto-fit/auto-fill` 常用于响应式网格。
- `position: relative` 保留原位置且可作为绝对定位参照；`absolute` 脱离文档流，参照最近的定位祖先；`fixed` 通常相对视口；`sticky` 在阈值内类似相对定位，越过阈值后吸附。

### 响应式与单位

- 移动端优先，使用媒体查询在空间足够时增强布局；`@media (min-width: ...)` 比设备型号更稳定。
- `rem` 相对根元素字号，`em` 相对当前元素字号（在字号属性中相对父元素），`%` 相对属性定义的参照物；`vw`/`vh` 相对视口。
- `min()`、`max()`、`clamp()` 可表达有边界的流式尺寸，例如 `font-size: clamp(1rem, 2vw, 2rem)`。
- 图片可使用 `max-width: 100%; height: auto` 防止溢出；为媒体指定宽高或 `aspect-ratio` 可减小布局偏移。

### 渲染与性能

- 重排（layout）会计算几何尺寸和位置，重绘（paint）只更新外观；合成（composite）把图层组合到屏幕。改变 `transform`、`opacity` 通常比改变几何属性更易于高效动画。
- `transform` 会创建新的包含块和层叠上下文；`z-index` 只能在同一层叠上下文内比较，不能无限抬高跨上下文的元素。
- 过渡需要属性有明确的起止值；动画使用 `@keyframes`，应尊重 `prefers-reduced-motion`。

### 现代层叠与作用域

- `@layer reset, base, components, utilities;` 显式定义层叠层顺序，低层高优先级选择器也无法越过更高 layer；未分层的作者普通样式通常位于分层样式之后。
- `:where()` 的优先级始终为 0，适合可覆盖默认样式；`:is()`、`:not()`、`:has()` 的优先级由其参数决定。
- `@scope` 可限制选择器的作用范围并定义下限，减少组件样式泄漏；使用前检查目标浏览器兼容性。
- CSS Nesting 允许在规则中嵌套选择器，但过深嵌套会增加耦合和优先级，应保持扁平。

```css
@layer reset, components, utilities;
@layer components {
  .card { padding: 1rem; & > h2 { margin-block: 0; } }
}
```

### Grid、Subgrid 与容器查询

```css
.gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(min(100%, 16rem), 1fr)); }
.card { container-type: inline-size; }
@container (width > 30rem) { .card__body { grid-template-columns: 1fr 2fr; } }
```

- Grid 显式网格定义轨道，隐式网格由超出项目产生；`minmax(0, 1fr)` 可避免内容最小尺寸造成溢出。
- `auto-fill` 保留可容纳的空轨道，`auto-fit` 折叠空轨道并扩展已有项。
- `subgrid` 让子 Grid 继承父级轨道，适合卡片内部标题/内容对齐。
- Container Query 根据容器而非视口响应，使组件可在不同布局复用；Style Query 可按自定义属性等条件应用样式，兼容性需核对。

### 自定义属性、函数与主题

```css
:root { --color-brand: oklch(62% .2 250); --space-2: .5rem; }
@media (prefers-color-scheme: dark) { :root { --color-surface: #111; } }
.title { font-size: clamp(1.25rem, 1rem + 2cqi, 2.5rem); }
```

- 自定义属性参与层叠并在使用时求值，可用于 token、主题和局部覆盖；与 Sass 变量的编译期替换不同。
- `var(--x, fallback)` 的 fallback 只在变量缺失/无效时使用；空字符串等合法值不会触发。
- `calc()`、`min()`、`max()`、`clamp()` 组合不同单位；容器单位 `cqi/cqb` 相对查询容器。
- `@property` 可声明自定义属性语法、继承和初始值，使颜色/长度变量可正确插值动画。

### 现代选择器与逻辑属性

- `:has()` 可根据后代/相邻元素选择父级，例如 `.field:has(:invalid)`；复杂大范围使用要注意可读性。
- `:focus-visible` 只在浏览器判断需要焦点指示时匹配，不应移除所有 outline。
- `:nth-child(... of selector)` 可在过滤后的兄弟集合中计数。
- `margin-inline`、`padding-block`、`inset-inline-start` 等逻辑属性适配书写方向和 RTL。
- `writing-mode`、`direction` 和逻辑属性应一起测试，不能只把文本右对齐当 RTL 支持。

### 滚动、媒体与用户偏好

- `scroll-snap-type`/`scroll-snap-align` 提供吸附滚动，但不能困住键盘和触摸用户。
- `overscroll-behavior` 控制滚动链和橡皮筋传播；`scrollbar-gutter` 可预留滚动条空间。
- `object-fit/object-position` 控制替换元素裁剪；`aspect-ratio` 提前确定尺寸。
- 响应 `prefers-reduced-motion`、`prefers-contrast`、`forced-colors`、`prefers-color-scheme` 等偏好。
- 打印使用 `@media print`，检查分页、链接、背景和隐藏交互控件。

## 面试常考题

### 1. 如何计算 CSS 选择器优先级？

分别统计 ID、类/属性/伪类、元素/伪元素的数量，按该顺序逐位比较；内联样式优先级更高。相同优先级看后声明者，`!important` 会先改变重要性层级，不能只靠选择器数量判断。

### 2. BFC 是什么，如何触发？

BFC 是块级格式化上下文，一个独立的布局区域。常见触发方式包括 `display: flow-root`、`overflow` 非 `visible/clip`、浮动、绝对定位和 Flex/Grid 容器。它可包含浮动、阻止与子元素的外边距折叠，并避免与浮动元素重叠。

### 3. Flex 中 `flex: 1` 是什么含义？

通常展开为 `flex-grow: 1; flex-shrink: 1; flex-basis: 0%`。项目先从零基础尺寸开始，再按增长因子分配可用空间；若希望按内容或指定宽度作为基础，需明确设置 `flex-basis`。

### 4. `display: none`、`visibility: hidden`、`opacity: 0` 的区别？

`display: none` 不占空间且不参与渲染；`visibility: hidden` 占空间但不可见；`opacity: 0` 占空间、可参与事件和焦点，因此制作视觉隐藏状态时还要处理交互与无障碍状态。

### 5. 为什么 `z-index: 9999` 仍可能被遮住？

因为它被限制在自己的层叠上下文中。`position` 配合 `z-index`、`transform`、`opacity < 1`、`filter`、`isolation` 等都可能创建新层叠上下文；要检查祖先上下文的层级关系，而不是只增大数值。

### 6. 水平垂直居中有哪些方式？

最常用的是父元素 `display: flex; justify-content: center; align-items: center`，或 Grid 的 `place-items: center`。已知元素尺寸时，可用绝对定位加 `transform: translate(-50%, -50%)`；应根据是否需要脱离文档流选择方案。

### 7. `:is()`、`:where()` 和 `:has()` 有什么区别？

`:is()` 合并多个选择器，其优先级取参数中最高值；`:where()` 匹配能力类似但优先级为 0；`:has()` 根据相对选择器匹配元素，可实现父选择和前向条件。

### 8. `auto-fill` 和 `auto-fit` 有什么区别？

二者都会创建尽可能多轨道；auto-fill 保留未被项目占用的空轨道，auto-fit 会折叠空轨道，让已有项目扩展填满剩余空间。

### 9. Container Query 与媒体查询有什么区别？

媒体查询根据视口或设备特征；容器查询根据组件容器尺寸/样式。容器查询让组件脱离页面级断点独立响应，但要先建立 containment。

### 10. CSS 自定义属性和 Sass 变量区别？

Sass 变量在构建时替换，不存在于浏览器层叠；CSS 自定义属性运行时存在、可继承、可被媒体查询和局部作用域覆盖，也可由 JavaScript 修改。

### 11. 如何实现不破坏可访问性的视觉隐藏？

不能使用 `display:none` 隐藏仍需屏幕阅读器读取的文本。可使用经典 visually-hidden 样式把元素裁剪为 1px，同时保留语义；可聚焦元素在 focus 时应恢复可见。
