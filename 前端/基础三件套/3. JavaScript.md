# JavaScript

## 常见知识点

### 基础类型与作用域

- 基本类型有 `undefined`、`null`、`boolean`、`number`、`bigint`、`string`、`symbol`；对象、数组、函数等属于引用值。
- `typeof null === 'object'` 是历史遗留问题；数组判断使用 `Array.isArray()`。
- `let` 与 `const` 是块级作用域，存在暂时性死区；`const` 限制绑定不可重新赋值，不表示对象内容不可变。`var` 是函数作用域且存在变量提升。
- 严格相等 `===` 不做类型转换，日常代码优先使用；`Object.is()` 可区分 `NaN` 与自身、`+0` 和 `-0`。

### 执行上下文、闭包与 this

- 执行上下文包含变量环境、词法环境和 `this` 绑定。函数声明整体提升，`var` 声明提升并初始化为 `undefined`，`let/const` 在初始化前不可访问。
- 闭包是函数与其创建时词法环境的组合，可封装状态；不再需要却被长期引用的闭包可能造成内存无法释放。
- 普通函数的 `this` 取决于调用方式：对象方法调用指向该对象，普通调用在严格模式下为 `undefined`，构造调用指向新实例；箭头函数没有自己的 `this`，从外层词法环境捕获。
- `call`、`apply` 立即指定 `this` 执行函数；`bind` 返回绑定后 `this` 的新函数。

### 原型与类

- JavaScript 基于原型实现继承。对象通过内部原型链查找属性，直到 `null`；自有属性可用 `Object.hasOwn()` 判断。
- 构造函数创建的实例通过 `[[Prototype]]` 连接到 `Constructor.prototype`；`class` 是原型继承的语法糖，并非传统类模型。
- `new` 会创建对象、连接原型、以新对象为 `this` 调用构造函数；若构造函数显式返回对象，则该对象成为结果。

### 异步、事件循环与 Promise

- JavaScript 执行栈一次执行一个任务；宿主环境提供定时器、网络和 DOM 事件等能力。
- 宏任务常见于整体脚本、`setTimeout`、I/O、UI 事件；微任务常见于 `Promise.then/catch/finally`、`queueMicrotask`、`MutationObserver`。
- 每个宏任务结束后，事件循环会清空微任务队列，再进行渲染机会与下一个宏任务。大量微任务会阻塞渲染。
- Promise 有 `pending`、`fulfilled`、`rejected` 三种状态，状态一旦敲定不可再变；`then` 总会返回新的 Promise。
- `async` 函数始终返回 Promise；`await` 会暂停当前 async 函数后续代码，并将其安排为微任务继续执行。

### 常用 API 与数据处理

- `map` 返回等长新数组，`filter` 返回满足条件的新数组，`reduce` 归并为单个结果；三者不直接修改原数组。
- `forEach` 返回 `undefined`，不会等待异步回调。串行异步使用 `for...of` 加 `await`，并行可用 `Promise.all()`。
- 展开运算符、`Object.assign` 都是浅拷贝；`structuredClone()` 支持许多内建类型的深拷贝，但不能克隆函数、DOM 节点等。
- 防抖在连续触发结束后一段时间执行，适合搜索输入；节流在固定时间间隔内最多执行一次，适合滚动、拖拽等高频事件。

### 模块与错误处理

- ES Module 静态声明依赖，默认严格模式，顶层 `this` 为 `undefined`；`import` 绑定是只读的实时绑定。
- `try/catch/finally` 处理同步异常和 `await` 的拒绝；未处理的 Promise 拒绝应统一监控，不应悄悄吞掉。
- `fetch()` 只会在网络错误时拒绝；HTTP 404/500 仍会正常 resolve，需要检查 `response.ok`。

### 类型转换与相等算法

- `ToPrimitive` 会先尝试 `Symbol.toPrimitive`，再按 hint 调用 `valueOf/toString`；对象参与字符串/数字运算时可能触发。
- `Number('')` 为 0，`Number(undefined)` 为 NaN；`Boolean([])` 和 `Boolean({})` 都为 true。
- `===` 使用严格相等，NaN 不等于自身且 +0 等于 -0；`Object.is` 让 NaN 等于自身并区分 ±0；Map/Set 使用 SameValueZero，NaN 可作为相同键且不区分 ±0。
- 空值判断可有意使用 `value == null` 同时匹配 null/undefined，其他业务比较优先严格相等。

### 属性描述符与对象完整性

属性描述符分数据描述符（value/writable）和访问器描述符（get/set），共同具有 enumerable/configurable。

```js
Object.defineProperty(user, 'id', { value: '1', writable: false, enumerable: true })
```

- `Object.keys` 只返回自有可枚举字符串键；`Reflect.ownKeys` 包含不可枚举和 Symbol 键；
- `Object.preventExtensions` 禁止新增，`seal` 还禁止删除/配置，`freeze` 再禁止数据属性写入；这些默认都是浅层；
- 对象属性顺序有规范规则，但业务协议不要无必要依赖顺序。

### Iterator、Generator 与异步迭代

可迭代对象通过 `[Symbol.iterator]()` 返回 Iterator，`for...of`、展开和 `Array.from` 消费该协议。

```js
function* range(start, end) {
  for (let i = start; i < end; i++) yield i
}
for (const n of range(0, 3)) console.log(n)
```

Generator 可暂停并恢复，适合惰性序列和状态遍历。Async Iterator 通过 `Symbol.asyncIterator` 和 `for await...of` 消费流式异步数据；循环退出时应触发资源清理。

### Map、Set、WeakMap 与 WeakSet

- Map 允许任意键并保持插入顺序，频繁键值操作比把普通对象当字典语义更清晰；
- Set 表示唯一值集合；对象去重仍按引用身份；
- WeakMap/WeakSet 的键必须是可垃圾回收对象（具体允许类型按规范版本），不会阻止键被回收且不可枚举；
- WeakMap 适合对象关联元数据和缓存，不适合需要统计/遍历的存储。

### Proxy 与 Reflect

```js
const reactive = new Proxy(target, {
  get(target, key, receiver) { return Reflect.get(target, key, receiver) },
  set(target, key, value, receiver) { return Reflect.set(target, key, value, receiver) },
})
```

Proxy 拦截对象基本操作，Reflect 提供与内部方法对应的默认行为。Proxy 必须遵守不可配置属性等 invariant；它不能透明代理带内部 slot 的所有内建对象，身份比较和性能也需考虑。

### 事件与 DOM 编程

- DOM 事件经历捕获、目标、冒泡；`stopPropagation` 阻止传播，`preventDefault` 阻止默认行为；
- 事件委托利用冒泡在祖先处理动态子节点，通过 `closest` 定位目标；
- `addEventListener` 支持 `once/passive/signal`，AbortSignal 可统一清理监听器；
- 自定义事件 `CustomEvent` 适合组件边界，但跨窗口/iframe 使用 `postMessage` 并验证 origin；
- DOM 写入与几何读取分批，避免强制同步布局。

### 异步控制、取消与并发

```js
const controller = new AbortController()
const timeout = setTimeout(() => controller.abort(), 3000)
try {
  const response = await fetch(url, { signal: controller.signal })
  if (!response.ok) throw new Error(`HTTP ${response.status}`)
} finally {
  clearTimeout(timeout)
}
```

- Promise 本身没有通用取消语义，取消通常通过 AbortSignal 传给支持的底层操作；
- 超时后只 reject 包装 Promise 并不会自动停止真实请求；
- 重试使用指数退避和抖动，只重试可恢复、幂等操作；
- 大批任务使用并发池，`Promise.all` 会同时启动所有已创建 Promise；
- 请求竞态使用取消、序列号或只接受最新请求结果。

### 垃圾回收与内存

垃圾回收以可达性为基础。常见泄漏来源：全局缓存无界增长、监听器/定时器未清理、闭包持有大对象、Detached DOM、未结束订阅和 Worker。

- WeakMap 只能解决特定对象键引用问题，不会自动清理 value 指向的其他全局对象；
- `FinalizationRegistry` 回调时机不可预测，不能用于关键资源释放；
- 使用 Heap Snapshot 的 Retainers 查明对象为何仍可达；
- 资源（Socket、文件、Observer）应显式关闭，不能依赖 GC。

### 元编程与常用现代语法

- 可选链 `?.` 遇到 null/undefined 短路；分组可能终止连续短路链；
- 空值合并 `??` 只处理 null/undefined，不会把 0、false、空字符串当缺失；
- 逻辑赋值 `||=`、`&&=`、`??=` 只在条件满足时赋值；
- `structuredClone` 支持循环引用、Map/Set、ArrayBuffer，并可转移 Transferable；
- `Intl` 提供日期、数字、货币、列表、相对时间和分词等国际化能力，优先于手写格式化。

## 面试常考题

### 1. `var`、`let`、`const` 有何区别？

`var` 是函数作用域，可重复声明，声明提升后值为 `undefined`。`let` 和 `const` 是块级作用域，初始化前处于暂时性死区，不能在同一作用域重复声明；`const` 必须初始化且不能重新绑定。

### 2. 什么是闭包？有哪些实际用途和风险？

闭包让内部函数保留对外层作用域变量的访问。它可用于私有状态、函数工厂、缓存和事件回调。风险是长期存活的回调持有大对象或 DOM 引用，导致这些资源不能及时被垃圾回收；应在不再需要时解除监听和引用。

### 3. 解释事件循环中宏任务与微任务的执行顺序。

同步代码先在当前调用栈执行。当前宏任务结束后会清空所有已入队的微任务，微任务执行过程中继续产生的微任务也会被处理；随后浏览器才可能渲染并取出下一个宏任务。因此 `Promise.then` 通常早于同一轮的 `setTimeout` 回调。

### 4. `==` 和 `===` 的区别？

`==` 会进行抽象相等比较，可能发生隐式类型转换，例如 `0 == false`。`===` 要求类型和值都相同，不做转换，更可预测，业务判断应优先用它。特殊值比较可根据需求使用 `Object.is()`。

### 5. `this` 的指向由什么决定？

普通函数的 `this` 在调用时确定，不取决于定义位置：`obj.fn()` 中通常是 `obj`，`fn()` 在严格模式中是 `undefined`，`new Fn()` 是新实例。箭头函数例外，它继承定义时外层的 `this`，不能用 `call/apply/bind` 改变。

### 6. Promise 的 `all`、`allSettled`、`race`、`any` 如何选择？

`Promise.all` 要求全部成功，任一失败即拒绝；`allSettled` 等待所有结果，适合批量任务汇总；`race` 以最先敲定的结果为准；`any` 以第一个成功结果为准，全部失败时才以 `AggregateError` 拒绝。

### 7. 如何实现浅拷贝和深拷贝？

浅拷贝可用 `{ ...obj }`、`Object.assign()`、`[...arr]`，嵌套对象仍共享引用。优先使用 `structuredClone()` 做通用深拷贝；JSON 序列化会丢失 `undefined`、函数、`Symbol`，并且不能正确表达 `Date`、`Map`、循环引用等，因此只适合受限的纯数据。

### 8. 为什么 `forEach` 中的 `await` 往往不符合预期？

`forEach` 不消费回调返回的 Promise，外层代码不会等待它们完成。需要串行时用 `for...of`，需要并发且等待全部完成时用 `await Promise.all(array.map(async item => ...))`。

### 9. `Object.is`、`===` 和 SameValueZero 有什么区别？

严格相等中 NaN 不等于自身、+0 等于 -0；Object.is 相反；SameValueZero 与严格相等基本一致，但认为 NaN 相等，Map、Set 和 includes 使用它。

### 10. Map 和普通对象如何选择？

Map 支持任意类型键、直接 size、稳定迭代和清晰字典语义；普通对象适合固定字段的数据记录和 JSON。若用对象作字典，应考虑原型键并使用 Object.create(null) 或 hasOwn。

### 11. Generator 有什么用途？

Generator 通过 yield 暂停/恢复执行，可实现惰性序列、自定义迭代器、遍历器和协程式控制。异步流使用 async generator 与 `for await...of`。

### 12. Proxy 为什么不能完全替代原对象？

Proxy 与 target 身份不同，某些内建对象方法依赖内部 slot 和正确 receiver；还必须遵守属性不变量。它也可能影响调试和性能，应明确代理边界。

### 13. 如何取消 fetch？

创建 AbortController，把 signal 传给 fetch，调用 abort 后 fetch 以 AbortError/对应原因拒绝。仅用 Promise.race 制造超时不会停止底层请求。

### 14. WeakMap 为什么有助于避免泄漏？

WeakMap 不会仅因为键存在于 Map 中就阻止键对象回收，适合关联元数据。但它不可遍历，value 仍可能引用其他对象，不能替代所有缓存淘汰策略。

### 15. `??` 和 `||` 有什么区别？

`||` 在左值为任意 falsy（0、false、空字符串、NaN 等）时取右值；`??` 只在 null/undefined 时取右值，适合保留合法的零值和空字符串。
