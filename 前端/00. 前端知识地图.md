# 前端知识地图

> 返回 [[00. 知识库导航|知识库导航]]。本页按能力而不是工具名称组织前端知识，目录清单由维护脚本同步。

## 知识结构

```text
语言与平台 -> 框架与应用 -> 工程与交付 -> 质量与体验 -> 架构与多端
     |             |              |              |              |
HTML/CSS/JS     React/Vue      构建/发布       测试/性能       Node/微前端
TypeScript      状态管理       包管理/CI       SEO/安全        跨端/WC
浏览器          全栈框架       Git Hooks       无障碍          浏览器插件
```

## 分阶段学习

### 1. 语言与浏览器平台

1. [[前端/基础三件套/00. 目录|HTML、CSS、JavaScript]]：语义、布局、语言机制和异步；
2. [[前端/TypeScript/TypeScript|TypeScript]]：类型系统、泛型、工程配置；
3. [[前端/浏览器/00. 目录|浏览器]]：导航、渲染、事件循环、存储、网络和安全；
4. [[前端/Web Components/00. 目录|Web Components]]：浏览器原生组件模型。

### 2. 框架与应用开发

1. [[前端/框架/00. 目录|框架目录]]：React、Vue、Next.js、Astro、Remix、Umi；
2. [[前端/框架/React/3. React 状态管理|React 状态管理]] 与 [[前端/状态机/状态机详解|状态机]]：区分 UI、客户端、服务端与流程状态；
3. [[前端/动画/00. 目录|动画]]：CSS、Web Animations API 与主流动画库；
4. [[前端/SEO/00. 目录|SEO]]：渲染策略、内容、结构化数据和监控。

### 3. 工程化与交付

1. [[前端/工程化/00. 目录|工程化]]：包管理、构建、编译、质量、CI/CD 与版本发布；
2. [[Git/00. Git知识地图|Git]]：分支协作、历史治理和恢复；
3. [[前端/前端测试/00. 目录|前端测试]]：单元、组件、契约、E2E、视觉与可访问性测试；
4. [[前端/性能优化/00. 目录|性能优化]]：指标、加载、渲染、内存和监控闭环。

### 4. 架构与平台扩展

1. [[前端/Node/00. 目录|Node.js]]：运行时、服务端框架和 ORM；
2. [[前端/微前端/00. 目录|微前端]]：拆分、隔离、通信、部署和治理；
3. [[前端/跨端与移动端/00. 目录|跨端与移动端]]：移动 Web、RN、Flutter、小程序、PWA 和桌面端；
4. [[前端/浏览器插件/00. 目录|浏览器插件]]：Manifest、权限、Service Worker 和内容脚本。

- [[前端/浏览器/6. 同源与Web安全|Web 安全]] 同时影响微前端、浏览器插件、跨端 WebView 与 Node API；
