# 国际化 SEO 与站点迁移

## 国际化 URL

推荐独立可抓取 URL，如 `/zh/`、`/en/` 或独立子域/域名。不要只靠 Cookie、浏览器语言或客户端状态切换内容而 URL 不变。

## hreflang

```html
<link rel="alternate" hreflang="zh-CN" href="https://example.com/zh-cn/page">
<link rel="alternate" hreflang="en" href="https://example.com/en/page">
<link rel="alternate" hreflang="x-default" href="https://example.com/page">
```

- 每个语言页面包含自身和所有替代页，形成互相引用；
- 使用合法语言/地区代码；
- hreflang URL 应可索引且 canonical 通常指向本语言自身；
- 自动跳转需允许用户切换，并避免阻止爬虫访问其他语言。

## 翻译质量

本地化标题、正文、货币、单位和结构化数据。机器批量生成低质量页面会产生薄内容和重复问题。

## 站点迁移

1. 爬取旧站并建立旧 URL -> 新 URL 一对一映射；
2. 保持内容、title、canonical、结构化数据和内部链接；
3. 先验证新站可抓取、状态码和性能；
4. 上线 301/308，更新 Sitemap、canonical 和外部重要链接；
5. 监控 404、索引、抓取、排名和流量；
6. 重定向长期保留，不建立多跳链。

域名、URL、CMS、渲染架构和内容同时大改会让归因与回滚困难，尽量分阶段迁移。
