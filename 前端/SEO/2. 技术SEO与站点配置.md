# 技术 SEO 与站点配置

## 状态码

- 200：有效页面；
- 301/308：永久迁移；302/307：临时；
- 404/410：不存在/明确永久删除；
- 5xx：服务器错误，会影响抓取和用户体验；
- Soft 404：返回 200 但内容表示不存在，应改为真实 404/410。

## robots.txt

```text
User-agent: *
Disallow: /admin/
Sitemap: https://example.com/sitemap.xml
```

robots.txt 控制抓取，不保证 URL 不被索引，也不是访问控制。敏感页面必须认证；需要阻止索引时页面可被抓取并返回 `noindex`。

## Sitemap

只包含规范、可索引、返回成功的 URL；使用准确 `lastmod`；大站拆分 Sitemap Index；图片/视频/新闻可使用扩展。Sitemap 是发现提示，不保证收录。

## Canonical

```html
<link rel="canonical" href="https://example.com/products/1">
```

canonical 是规范化提示。目标应可索引、返回 200；内部链接、Sitemap、重定向与 canonical 保持一致。不要所有分页都指向第一页，除非内容确实等价。

## Meta Robots

```html
<meta name="robots" content="noindex,follow">
```

`noindex` 阻止索引；`nofollow` 是链接处理提示。若 robots.txt 禁止抓取，爬虫可能看不到页面中的 noindex。

## 页面基础标签

- 每页唯一、准确的 `<title>`；
- description 提升摘要表达，但不保证排名或一定被采用；
- 唯一主标题与清晰 H1-H6 层级；
- 图片有语义化 alt，装饰图使用空 alt；
- HTTPS、移动适配、稳定主机名和无重定向链。

## 分页与筛选

分页页应可访问并自引用 canonical；筛选参数按搜索价值决定可索引集合，低价值组合 noindex/禁止生成内部链接，避免抓取空间爆炸。
