# SEO 监控与审计

## 数据来源

- Search Console：索引、抓取、搜索查询、Core Web Vitals、结构化数据；
- Web Analytics：自然搜索落地、转化、留存；
- 服务端日志：真实爬虫请求、状态码和抓取频率；
- 爬虫工具：内部链接、canonical、标题、状态码和深度；
- RUM：真实性能与错误。

## 定期审计

1. 可抓取/可索引性：robots、noindex、状态码；
2. 重复与规范化：canonical、参数、http/https、www；
3. Sitemap 与内部链接；
4. Title、description、H1、alt 和内容质量；
5. 结构化数据错误；
6. 移动体验和 Web Vitals；
7. 404、Soft 404、重定向链和 5xx；
8. 自然流量、展示、CTR、排名与转化。

## 上线门禁

- 生产环境没有误带 noindex；
- robots.txt 和 Sitemap 指向正式域名；
- SSR 页面返回完整内容与真实状态码；
- canonical/hreflang 使用绝对正确 URL；
- 关键页面的 title/description/OG/JSON-LD 正确；
- 旧 URL 重定向、404 和性能通过检查。

## 排查流量下降

先区分技术故障、追踪问题、季节/需求、算法变化和竞争。按日期关联发布；检查索引、状态码、robots、canonical、页面内容、模板和关键查询。不要看到下降就立即批量改标题。

## 指标

抓取成功率、索引覆盖、有效页面数、非品牌展示/点击、CTR、落地页转化、Web Vitals p75、富媒体有效数和迁移 404 数。排名只是中间指标，最终关注合格自然流量和业务价值。
