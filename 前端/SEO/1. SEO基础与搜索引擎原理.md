# SEO 基础与搜索引擎原理

SEO 是帮助搜索引擎发现、理解、索引并展示网页，同时为用户提供高质量体验的工程与内容实践。它不能保证排名，排名受内容价值、相关性、权威性、体验和搜索意图共同影响。

## 工作流程

1. Discovery：通过链接、Sitemap、提交入口发现 URL；
2. Crawl：爬虫请求页面及资源，受 robots、状态码、容量影响；
3. Render：必要时执行 JavaScript 获得最终内容；
4. Index：规范化、理解内容并选择是否收录；
5. Rank/Serve：按查询意图、相关性、质量和上下文返回结果。

“可抓取”不等于“会索引”，“已索引”不等于“有排名”。

## 搜索意图

- 信息型：教程、解释；
- 导航型：寻找特定品牌/页面；
- 商业调查：对比、评测；
- 交易型：购买、注册、下载。

页面内容、标题、结构和 CTA 应匹配真实意图，避免为关键词堆砌重复页面。

## URL 与信息架构

- URL 稳定、可读、层级合理，使用连字符；
- 重要页面从导航或正文获得内部链接，避免孤岛页；
- 面包屑表达层级；
- 参数、筛选和分页可能制造重复 URL，需要 canonical、noindex 或抓取治理；
- URL 变更使用服务端 301/308 一跳重定向并更新内部链接。

## 常见误区

- Meta keywords 已不是现代主流搜索排名依据；
- 只提交 Sitemap 不能修复内容质量和内部链接；
- CSR 不等于一定不能 SEO，但渲染成本和失败面更高；
- Core Web Vitals 重要，但不能替代相关内容；
- 隐藏文字、链接农场和批量低质内容可能受到惩罚。
