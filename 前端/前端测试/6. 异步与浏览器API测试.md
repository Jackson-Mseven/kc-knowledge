# 异步与浏览器 API 测试

异步测试的核心是等待业务可观察结果，而不是猜测完成时间。测试必须处理取消、竞态、失败和清理。

## 1. Promise 与错误

```ts
await expect(loadUser('1')).resolves.toMatchObject({ id: '1' })
await expect(loadUser('missing')).rejects.toThrow('Not found')
```

必须 return/await Promise，否则测试可能在断言运行前结束。验证错误时同时检查稳定错误码，不依赖易变化的完整文案。

## 2. 等待 UI

- `findBy*` 等待元素出现；
- `waitFor` 重试其中断言，回调应只放断言而非重复副作用；
- `waitForElementToBeRemoved` 等待 loading 消失；
- 不使用 sleep 修复竞态；它会让测试慢且仍可能失败。

## 3. 请求竞态与取消

覆盖“先发 A，后发 B，但 A 更晚返回”的场景，确保旧响应不覆盖新 UI。组件卸载或查询变化时使用 AbortController/库取消机制，并验证不会产生未处理错误。

## 4. 浏览器存储

- 每个测试清空 localStorage/sessionStorage/IndexedDB；
- 测试 JSON 损坏、配额失败、隐私模式或 API 不可用的降级；
- Cookie 测试关注 Secure、HttpOnly、SameSite 主要需要服务端集成/E2E，jsdom 无法完整模拟。

## 5. Observer 与媒体查询

IntersectionObserver、ResizeObserver、matchMedia 常需小型 Fake。Fake 应允许测试主动触发 intersect/resize/change，而不是只返回空方法。

## 6. 文件、剪贴板和权限

- 组件测试可构造 `File` 并触发上传；
- 下载、系统文件选择器、权限提示使用浏览器 E2E；
- Clipboard、Geolocation 等 API Mock 同时覆盖拒绝权限和异常；
- 测试后恢复全局属性，避免污染其他用例。

## 7. WebSocket 与 SSE

协议层应测试连接、消息解析、心跳、断线重连、指数退避、重复/乱序消息和取消订阅。组件测试可使用 fake server；关键流程在集成环境验证代理、认证和真实连接。

## 8. Service Worker

单测缓存策略函数；集成/E2E 验证 install/activate、离线回退、更新等待、新旧缓存兼容和清理。Service Worker 状态依赖浏览器和 origin，模拟 DOM 测试不足以证明真实行为。
