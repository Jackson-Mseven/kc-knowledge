# Lottie 与 Rive

Lottie 和 Rive 主要解决设计工具产出的矢量/角色动画运行，而非普通 DOM 补间。

## Lottie

Lottie 播放由 After Effects 等导出的 JSON 动画，可使用 SVG/Canvas 渲染。适合品牌动效、空状态、加载和图标动画。

优点：设计交付成熟、视觉还原好；缺点：复杂 JSON 体积和 CPU 较高，不是所有 AE 特性都支持，动态交互能力有限。

## Rive

Rive 资源可包含状态机、输入和交互逻辑，运行时使用 Canvas/WebGL 等。适合交互角色、复杂按钮、游戏化 UI 和状态驱动动画。

优点：状态机和交互强、资源紧凑；缺点：专用设计工作流、运行时集成和调试成本更高。

## 实践

- 首屏非关键动画延迟加载，资源使用 CDN 和缓存；
- 提供静态 fallback，加载失败不影响操作；
- 暂停不可见/后台动画；
- 不在动画文件中承载关键文字和可访问信息；
- 对低端设备、DPR、内存和 reduced motion 测试；
- Lottie 资源导出后压缩、删除隐藏层，并检查实际渲染方式。

## 选择

线性设计动画和 AE 流程选 Lottie；需要状态机、输入响应和角色交互选 Rive；普通 DOM 动画不必引入二者。
