# GSAP

GSAP 是成熟的通用动画平台，强项是高性能补间、Timeline、复杂编排、SVG 和滚动动画，适合品牌站、叙事页面、复杂交互和跨技术栈项目。

```js
const timeline = gsap.timeline({ defaults: { duration: .5, ease: 'power2.out' } })
timeline.from('.title', { y: 24, opacity: 0 })
        .from('.card', { y: 16, opacity: 0, stagger: .08 }, '-=.2')
```

## 核心能力

- `gsap.to/from/fromTo/set`；
- Timeline 标签、重叠、暂停、倒放和 seek；
- ScrollTrigger、Flip、MotionPath 等插件；
- Context/组件集成用于批量回收动画。

## 优劣势

优点：时间线表达力强、生态成熟、跨 DOM/SVG/Canvas 对象、复杂动画稳定。缺点：包体和学习成本高于原生方式；部分高级插件授权需核对；简单 hover 使用它过重。

## 注意事项

在 React/Vue 生命周期内创建并 revert/kill；优先 transform；ScrollTrigger 刷新时考虑图片字体和布局变化；不要让多个 timeline 同时争夺同一属性。
