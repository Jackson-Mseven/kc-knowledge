# 前端动画基础

前端动画最基础的实现方式可以分为 CSS 动画、Web Animations API、JavaScript 逐帧动画，以及 SVG/Canvas/WebGL 绘制动画。选择依据是交互控制、动画复杂度、元素数量、渲染方式和可访问性。

## 1. CSS Transition

适合从一个明确状态过渡到另一个状态，例如 hover、展开、显隐：

```css
.button {
  transition: transform 180ms ease, opacity 180ms ease;
}
.button:hover { transform: translateY(-2px); }
```

优点是简单、浏览器可优化；缺点是时间线、暂停、倒放和复杂编排能力有限。不要使用 `transition: all`，应明确动画属性。

## 2. CSS Keyframes

适合循环、多个关键帧和进入/离开效果：

```css
@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 1; }
  50% { transform: scale(.96); opacity: .7; }
}
.loading { animation: pulse 1s ease-in-out infinite; }
```

关键配置包括 duration、delay、timing-function、iteration-count、direction、fill-mode 和 play-state。

## 3. Web Animations API（WAAPI）

WAAPI 用 JavaScript 创建由浏览器管理的动画，并提供播放控制：

```js
const animation = element.animate(
  [{ opacity: 0, transform: 'translateY(12px)' }, { opacity: 1, transform: 'none' }],
  { duration: 240, easing: 'ease-out', fill: 'both' },
)
animation.pause()
animation.play()
```

适合需要动态参数、暂停、反向和组合控制，但又不需要完整第三方时间线系统的场景。

## 4. requestAnimationFrame

适合物理模拟、Canvas 绘制和必须逐帧读取/计算的动画：

```js
let start
function frame(time) {
  start ??= time
  const progress = Math.min((time - start) / 500, 1)
  element.style.transform = `translateX(${progress * 200}px)`
  if (progress < 1) requestAnimationFrame(frame)
}
requestAnimationFrame(frame)
```

基于回调时间戳计算进度，不要假设每帧固定 16.7 ms。页面隐藏时 rAF 会降频，动画必须能处理跳帧。

## 5. SVG、Canvas 与 WebGL

| 技术 | 适合 | 特点 |
| --- | --- | --- |
| SVG | 图标、路径、少量可交互矢量元素 | DOM 可访问、CSS/JS 可控制；节点过多会慢 |
| Canvas 2D | 粒子、图表、大量绘制对象 | 单画布性能好；需自行处理命中、状态与可访问性 |
| WebGL/WebGPU | 3D、大量粒子、GPU 特效 | 性能强，开发和资源管理复杂 |

SVG 路径动画常使用 `stroke-dasharray/stroke-dashoffset`；Canvas 每帧清除并重绘；WebGL 通常由 Three.js 等引擎管理场景、材质和相机。

## 6. 补间、关键帧、弹簧与时间线

- Tween：在起止值之间插值；
- Keyframe：在多个时间点定义状态；
- Spring：由刚度、阻尼、质量决定运动，不以固定 easing 为核心；
- Timeline：统一编排多个动画的开始、重叠、标签和顺序；
- Gesture：拖拽、滑动、按压等输入驱动动画。

## 7. 性能原则

- 优先 transform 和 opacity，减少 layout/paint；
- 批量读布局、批量写样式，避免布局抖动；
- 不为所有元素添加 `will-change`，仅在确认热点时短期使用；
- 大量对象考虑 Canvas/WebGL，不要创建数万个 DOM/SVG 节点；
- 用 DevTools Performance、Layers 和低端移动设备验证。

## 8. 可访问性

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    scroll-behavior: auto !important;
  }
}
```

减少运动不必移除所有状态反馈，应替换大位移、视差和持续旋转。动画不能成为获取信息或完成操作的唯一方式；避免闪烁、眩晕和阻止用户操作。
