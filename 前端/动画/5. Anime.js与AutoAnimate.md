# Anime.js 与 AutoAnimate

## Anime.js

Anime.js 是轻量通用 JavaScript 动画库，支持 CSS、DOM 属性、SVG、对象数值、stagger 和 timeline。

```js
animate('.item', { translateY: [20, 0], opacity: [0, 1], delay: stagger(60) })
```

适合中等复杂补间、SVG 和无需绑定特定框架的页面。优点是 API 简洁、体积相对克制；缺点是生态和高级滚动/编排能力通常不如 GSAP，框架生命周期需自行管理。

## AutoAnimate

AutoAnimate 观察容器直接子节点的添加、删除和移动，自动生成过渡：

```js
const cleanup = autoAnimate(document.querySelector('.list'))
```

适合表单错误、列表排序、折叠内容等“零配置”布局变化。优点是接入极快；缺点是精确控制、复杂时间线和深层动画有限。

## 注意事项

- 自动布局动画仍依赖 DOM 尺寸测量，大列表先做虚拟化；
- 组件卸载时清理实例；
- 动态内容尺寸、absolute 定位和特殊布局要验证；
- reduced motion 和用户操作期间的中断必须测试。
