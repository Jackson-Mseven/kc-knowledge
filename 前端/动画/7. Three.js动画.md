# Three.js 动画

Three.js 是 WebGL 3D 引擎，提供场景、相机、网格、材质、灯光、动画混合器和加载器。适合 3D 产品、数据空间、游戏和沉浸体验。

```js
const clock = new THREE.Clock()
renderer.setAnimationLoop(() => {
  const dt = clock.getDelta()
  mixer?.update(dt)
  mesh.rotation.y += dt * .5
  renderer.render(scene, camera)
})
```

## 动画方式

- 每帧更新 position/rotation/material；
- AnimationMixer 播放 glTF 骨骼/关键帧动画；
- GSAP 驱动相机和对象属性；
- Shader uniforms 实现粒子、波动和后处理。

## 性能

控制 draw call、三角面、纹理尺寸、灯光和后处理；复用 Geometry/Material；大量相同对象用 InstancedMesh；资源使用 glTF/Draco/KTX2；按设备调整 DPR 和质量。

## 注意事项

销毁 geometry、material、texture、render target；处理 WebGL context lost；提供 loading、错误和降级内容；3D 主体验需要真实资源和移动端触控/性能验证；Canvas 外提供可访问文本和操作替代。
