# Electron 与 Tauri

## Electron

Electron 打包 Chromium 和 Node.js，由 Main Process 管理窗口/系统能力，Renderer 渲染 Web UI，Preload 通过 contextBridge 暴露受控 API。

```js
// preload.js
const { contextBridge, ipcRenderer } = require('electron')

contextBridge.exposeInMainWorld('files', { readText: (path) => ipcRenderer.invoke('files:readText', path) })
```

```js
// main.js
const { ipcMain } = require('electron')
const { readFile } = require('node:fs/promises')

ipcMain.handle('files:readText', async (event, path) => {
  assertTrustedSender(event.senderFrame.url)
  assertAllowedPath(path)
  return readFile(path, 'utf8')
})
```

安全基线：`contextIsolation: true`、`nodeIntegration: false`、启用 sandbox、限制导航/新窗口、校验 IPC sender 和参数。Renderer 不得获得任意 fs/shell。

## Tauri

Tauri 使用系统 WebView 和 Rust 后端，包体/内存通常更小，通过 Command/权限 Capability 暴露原生能力。代价是各系统 WebView 差异、Rust/原生调试和平台依赖。

```rust
#[tauri::command]
fn greet(name: &str) -> String {
    format!("你好，{name}")
}

tauri::Builder::default()
    .invoke_handler(tauri::generate_handler![greet])
    .run(tauri::generate_context!())
    .expect("tauri application failed");
```

前端通过 `invoke('greet', { name: 'Ada' })` 调用。Command 仍是信任边界，需要校验输入并使用 Capability/权限配置限制窗口可调用的命令。

## 对比

| 维度 | Electron | Tauri |
| --- | --- | --- |
| Web 引擎 | 自带 Chromium，一致性强 | 系统 WebView，体积小但有差异 |
| 后端 | Node.js | Rust |
| 包体/内存 | 较高 | 通常较低 |
| 生态 | 成熟 | 快速发展 |
| 原生能力 | Node/Native Addon | Command/Plugin/Rust |

## 桌面能力

窗口、托盘、菜单、快捷键、文件协议、自动更新、Deep Link、通知、系统权限。所有外部输入、文件路径和 URL 都需校验。

桌面端还要处理单实例锁、文件关联、拖放、多窗口状态、崩溃恢复、代理、系统睡眠和多显示器。不要把窗口关闭、隐藏到托盘和真正退出混为一谈。

## 进程与任务划分

Electron 主进程负责窗口和特权能力，Renderer 只负责 UI；CPU 密集任务放 Worker Thread/Utility Process，不能阻塞主进程事件循环。Tauri 把高权限和高性能任务放 Rust Command/异步任务，前端仍保持最小权限。

IPC 只传结构化小数据。大文件使用受控文件句柄、流或临时文件，事件订阅在窗口销毁时注销。IPC channel 视为内部 API，做类型、超时、错误码和版本治理。

## 发布

Windows/macOS/Linux 分别签名、notarization/安装包和自动更新。更新包签名并支持回滚；Source Map 与原生崩溃关联版本；测试多显示器、DPI、睡眠唤醒和离线。

Electron 要关注 Chromium/Node 安全更新并及时升级；Tauri 同时关注框架、Rust crate 和系统 WebView。发布物生成 SBOM/依赖审计，签名密钥只在受保护 CI 环境使用。

## 选型

需要浏览器一致性、Node 生态和成熟方案选 Electron；重视体积、内存和安全能力白名单且团队能维护 Rust 选 Tauri。
