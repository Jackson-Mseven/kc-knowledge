# Flutter

Flutter 使用 Dart 和自绘渲染体系构建移动、Web、桌面应用。Widget 描述不可变配置，Element 管理实例关系，RenderObject 负责布局绘制。

## 基础示例

```dart
class Counter extends StatefulWidget {
  const Counter({super.key});

  @override
  State<Counter> createState() => _CounterState();
}

class _CounterState extends State<Counter> {
  int count = 0;

  @override
  Widget build(BuildContext context) {
    return Column(
      mainAxisAlignment: MainAxisAlignment.center,
      children: [
        Semantics(liveRegion: true, child: Text('$count')),
        ElevatedButton(
          onPressed: () => setState(() => count++),
          child: const Text('增加'),
        ),
      ],
    );
  }
}
```

`build` 可能频繁执行，应保持纯净和轻量。网络请求、订阅和控制器分别在 `initState`、`didChangeDependencies`、`dispose` 等生命周期中管理，并在异步返回后检查 `mounted`。

## 核心能力

- Material/Cupertino Widget、Layout、Theme；
- Navigator/Router、Deep Link；
- Future/Stream、Isolate；
- Platform Channel/FFI 调用原生；
- Implicit/Explicit Animation、Hero；
- DevTools 性能、Widget Inspector 和内存工具。

Flutter 采用 constraints go down、sizes go up、parents set positions 的布局模型。父节点下发约束，子节点选择约束内尺寸，父节点再定位；大量“为什么宽高不生效”的问题都应先检查约束链。

## 状态与架构

局部使用 setState/ValueNotifier；复杂应用可使用 Provider、Riverpod、Bloc 等。业务层与 Widget 分离，避免在 build 中发请求或创建持续资源。

```text
lib/
  app/            # Router、Theme、依赖装配
  features/       # 页面、状态、业务用例
  domain/         # 实体与仓储接口
  data/           # HTTP、数据库和仓储实现
  shared/         # 通用组件与工具
```

状态库不是架构本身。先区分临时 UI 状态、跨页面应用状态和服务端缓存，再决定是否需要 Riverpod/Bloc；Repository 隔离接口与本地存储，便于测试和离线同步。

## 导航与平台集成

简单页面跳转可用 Navigator；Web Deep Link、嵌套路由和鉴权重定向更适合 Router API 或 go_router。路由参数应能从 URL 恢复，不能只依赖内存对象。

Platform Channel 适合调用 Kotlin/Swift API，Pigeon 可生成类型安全通道；C ABI 库可使用 `dart:ffi`。所有跨端接口都要定义错误、取消、线程、版本兼容和权限拒绝语义。

## 性能

控制 build 范围、使用 const Widget、长列表 builder、图片尺寸和 RepaintBoundary。掉帧区分 UI 线程、Raster 线程、Shader/资源加载。计算密集任务使用 Isolate，但通信有复制成本。

使用 Profile 模式和 DevTools 的 Performance、CPU Profiler、Memory 分析，Debug 模式帧率不能代表发布性能。`RepaintBoundary` 只在确实隔离高频重绘时使用，过多会增加图层和内存。

## 测试与发布

- Unit Test：领域逻辑、Repository 和序列化；
- Widget Test：在测试渲染树中验证交互、语义和不同尺寸；
- Integration Test：真机覆盖登录、权限、Deep Link、后台恢复；
- Golden Test：稳定字体和平台环境后验证关键视觉；
- 发布：分别管理 Android signing、iOS certificate/profile、商店隐私声明和崩溃符号。

## 优劣势

多端视觉一致、动画和自绘能力强；代价是 Dart/Flutter 独立生态、引擎包体、平台原生集成、Web DOM/SEO 差异。内容网站通常不应仅因跨端选择 Flutter Web。
