# Custom Elements 与生命周期

Custom Elements 允许类继承标准元素，并注册为浏览器可识别的自定义标签。生产实现的重点不是 `define` 本身，而是稳定的属性协议、可重复生命周期和资源清理。

## 定义与防重复注册

```ts
class StatusBadge extends HTMLElement {
  connectedCallback() {
    if (!this.hasAttribute('role')) this.setAttribute('role', 'status')
    this.textContent = this.getAttribute('label') ?? '未知'
  }
}

if (!customElements.get('acme-status-badge')) {
  customElements.define('acme-status-badge', StatusBadge)
}
```

库通常不应静默允许不同版本用同一标签覆盖。`get()` 防止开发热更新时报错，但也可能掩盖版本冲突；发布的设计系统应统一标签前缀和加载策略。

## 生命周期回调

| 回调 | 触发时机 | 典型用途 |
| --- | --- | --- |
| `constructor()` | 实例创建/升级 | 初始化纯内部状态、创建 Shadow Root |
| `connectedCallback()` | 节点连接到 Document | 渲染、订阅外部事件、启动观察器 |
| `disconnectedCallback()` | 节点离开 Document | 移除监听、断开观察器、取消请求 |
| `attributeChangedCallback()` | 受观察属性变化 | 将外部配置同步到内部状态/UI |
| `adoptedCallback()` | 节点被移动到另一个 Document | 处理 ownerDocument 相关资源 |

构造函数中不要读取尚不可靠的子节点和 Attribute，也不要插入复杂内容或发请求。解析器、`createElement()` 和 upgrade 的时序不同，连接后再处理外部 DOM 更稳妥。

`connectedCallback()` 可能执行多次：节点排序、条件渲染、路由缓存或跨容器移动都会断开再连接。订阅逻辑必须幂等，清理逻辑也应允许重复调用。

```ts
class OnlineIndicator extends HTMLElement {
  #abortController?: AbortController

  connectedCallback() {
    this.#abortController?.abort()
    this.#abortController = new AbortController()

    window.addEventListener('online', this.#render, {
      signal: this.#abortController.signal,
    })
    window.addEventListener('offline', this.#render, {
      signal: this.#abortController.signal,
    })
    this.#render()
  }

  disconnectedCallback() {
    this.#abortController?.abort()
    this.#abortController = undefined
  }

  #render = () => {
    this.textContent = navigator.onLine ? '在线' : '离线'
  }
}
```

AbortSignal 能统一清理事件监听和 Fetch，但 `MutationObserver`、`ResizeObserver`、定时器及部分第三方实例仍需显式释放。

## Attribute 与 Property

Attribute 是 HTML 字符串协议，适合可声明、可序列化的简单值；Property 是 JavaScript 对象属性，可以承载对象、函数和运行时状态。

```html
<user-card user-id="42" compact></user-card>
```

```js
const card = document.querySelector('user-card')
card.user = { id: 42, name: 'Ada' }
card.onResolve = (result) => console.log(result)
```

建议规则：

- String/Number/Boolean/枚举等简单配置可映射 Attribute；
- 对象、数组、函数、实例使用 Property，避免塞进 JSON Attribute；
- 对外状态变化通过 Event 通知，不用消费者轮询内部 Property；
- Property 名通常用 camelCase，Attribute 使用 kebab-case；
- 明确默认值、非法输入和移除 Attribute 的语义。

## 观察 Attribute

```ts
class ProgressRing extends HTMLElement {
  static observedAttributes = ['value', 'max']

  attributeChangedCallback(name: string, oldValue: string | null, newValue: string | null) {
    if (oldValue === newValue) return
    this.#render()
  }

  get value() {
    return Number(this.getAttribute('value') ?? 0)
  }

  set value(value: number) {
    this.setAttribute('value', String(value))
  }

  get max() {
    return Number(this.getAttribute('max') ?? 100)
  }

  #render() {
    const max = Number.isFinite(this.max) && this.max > 0 ? this.max : 100
    const value = Math.min(Math.max(this.value, 0), max)
    this.textContent = `${Math.round((value / max) * 100)}%`
  }
}
```

`attributeChangedCallback` 可能在连接前执行，所以不要假设元素已在 Document 中。若渲染依赖布局或完整子节点，可先保存状态，在连接后渲染。

## Boolean Attribute

HTML Boolean Attribute 只看“是否存在”，而不是字符串内容：

```html
<app-dialog open></app-dialog>          <!-- true -->
<app-dialog open="false"></app-dialog>  <!-- 仍然是 true -->
```

```ts
get open() {
  return this.hasAttribute('open')
}

set open(value: boolean) {
  this.toggleAttribute('open', value)
}
```

消费者要关闭它，应移除 Attribute 或把 Property 设为 `false`。

## Property 与 Attribute 反射

反射是 Property 更新 Attribute，或 Attribute 更新 Property。只在状态需要出现在 HTML、CSS 选择器、序列化或无障碍树时使用，避免所有字段双向反射导致循环和额外 DOM 变更。

```ts
set variant(value: 'info' | 'danger') {
  const next = value === 'danger' ? 'danger' : 'info'
  if (this.getAttribute('variant') !== next) {
    this.setAttribute('variant', next)
  }
}
```

区分初始配置与实时状态。例如 `default-value` 只设初值，`value` Property 表示当前输入值，这与原生表单控件的 `defaultValue/value` 模型更接近。

## 更新调度

多个属性在同一任务内连续变化时，立即重复渲染会浪费工作。可用微任务合并更新：

```ts
class BatchedElement extends HTMLElement {
  #updatePending = false

  requestUpdate() {
    if (this.#updatePending) return
    this.#updatePending = true

    queueMicrotask(() => {
      this.#updatePending = false
      if (this.isConnected) this.render()
    })
  }

  render() {}
}
```

复杂组件更适合使用 Lit 等已经处理响应式属性、更新批次和模板复用的库，不必自行实现一个不完整框架。

## DOM 移动与断开重连

消费者可能用 `append`、排序库或框架 reconciliation 移动元素，传统生命周期会出现 disconnect/connect。不要在短暂断开时销毁不可恢复的用户状态；把持久状态放在元素 Property/外部 Store，把连接相关资源与状态分开。

不同 Document/iframe 之间 adopt 后，`ownerDocument`、样式表、Window 级监听和 Realm 中的构造函数可能变化。依赖全局对象时优先使用 `this.ownerDocument.defaultView`，而不是无条件引用顶层 `window`。

## 常见错误

- 在构造函数读取 Attribute/子节点并假设解析已完成；
- 每次连接重复创建 Shadow Root 或重复注册监听；
- 只清理 DOM 监听，遗漏 Observer、Promise 后续写入、计时器和第三方实例；
- 把对象 `JSON.stringify` 到 Attribute，产生长度、转义与更新成本；
- Attribute 和 Property 互相写入形成无限反射；
- 用内部实现状态充当公共 API，导致未来无法重构；
- 在模块顶层无条件重复 `define()`，测试或 HMR 时抛异常。
